## Release Notes:

---

### 🆕 Added
- `App`: Release note for the old version `0.1.0`
- `Weight`: Tabs in `Weight Monitor` page for better organizing and control
- `Weight`: Tab `Overview` in `Weight Monitor` module
- `Weight`: `Overview` tab's UI page in `Weight Monitor` module
- `Weight`: Tab `Week` in `Weight Monitor` module
- `Weight`: `Week` tab's UI page in `Weight Monitor` module
- `Weight`: Tab `Month` in `Weight Monitor` (Tab `Month` remains under construction for now)
- `Weight`: Improve the `Weight Monitor` chart/graph layout
- `Weight`: Improve the `Weight Monitor` chart/graph animations
- `Settings`: Option `Animate Navigation Drawer` in `Setting` -> `Appearance`
- `Navigation`: Groups to `Navigation Drawer` for better organization and visibility

---

### 🪲 Fixed
- `App`: Some crashes caused by API changes
- `Weight`: A visual bug caused the `Weight Monitor` to seem like it doesn't save old weight, caused by reverse ordering of the dates
- `Weight`: Zero-weight days showing on the `Weight` graph, now correctly translating between days with actual data
- `Dashboard`: `Dashboard` module cards click not working after the `Navigation` API rework

---

### 🔃 Updated
- `Navigation`: Rework `Navigation` system, improving performance and adding internal features
- `Navigation`: Move `Navigation Drawer` expand icon and app name to the `Title Bar` on `Desktop` platforms for a more dynamic look
- `Navigation`: Improve `Navigation Drawer` expand/collapse events handling and performance
- `Navigation`: Increase the speed of which the `NavDrawer` expand/collapse (from 1000ms to 500ms)
- `App`: Update the app to use the new `Navigation` system
- `Weight`: Rework `Weight Monitor` page
- `Settings`: `Settings` page no longer reloads when changing theme, keeping the state, scroll position, and expanded/collapsed foldables
