## Release Notes:

---

### 🆕 Added
- `Security`: Add: Custom encryption to the app, providing extra security layers for user's data
- `Update`: Check for new `Axis` release on start-up on `Desktop` platforms
- `UI`: Tooltips to Buttons
- `Google`: Add the foundation for `Google Authorization`
- `Google Drive`: `Google Drive` account connect functionality
- `Backup`: `Google Drive Backup` backup functionality
- `Backup`: `Google Drive Backup` restore functionality
- `Navigation`: Color to the `Navigation Drawer` expand icon for better visibility
- `Settings`: Backup section to `Settings`
- `Settings`: `Connect Google Drive` button in `Settings` -> `Backup` section
- `Settings`: `Backup Now` button and functionality in `Setting` -> `Backup`
- `Settings`: `Restore` button and functionality in `Setting` -> `Backup`
- `Settings`: `DevMode` warning and explanation in `Settings` -> `Development`
- `Settings`: `Update` section in `Settings` with `Update Interval` options and `Check for Updates` button
- `Dialog`: Error dialog now shows a red border and background for better visibility
- `DB`: `DB` compacting functionality to accommodate `Google Drive Backup` system
- `Log`: Multi-platform logging utils
- `Log`: Logging to files for easy bug submission

---

### 🪲 Fixed
- `App`: Some crashes caused by API changes
- `Weight`: A visual bug caused the `Weight Monitor` to seem like it doesn't save old weight, caused by reverse ordering of the dates
- `Weight`: Zero-weight days showing on the `Weight` graph, now correctly translating between days with actual data
- `Dashboard`: `Dashboard` module cards click not working after the `Navigation` API rework

---

### 🔃 Updated
- `App`: Rework app `exit` process, increasing the performance and stability
- `UI`: Update Some `UI` elements for more performance and stability
- `Config`: Update App Configs System
- `DB`: Migrate `DB` system to `Google Drive Backup` integration system
- `Weight`: Migrate `Weight` module to `Google Drive` backup integration system
- `Weight`: Improve `Weight` chart/graph colors
- `Todo`: Migrate `Todo` module to `Google Drive Backup` integration system
- `Todo`: Improve `Todo` system stability and appearance
- `Dialog`: Rework `Dialog` module, increasing performance and stability; and update dependent modules
- `Dialog`: Update dependent modules to use the new `Dialog` system
- `File`: Update internal `File` management system, adding more functionality
- `Log`: Rework logging system, increasing performance, stability, and add more functionalities
- `Build`: Implemented APIs to higher versions
